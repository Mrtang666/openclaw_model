# 百度网盘文件

## 执行流程

1. 用户未授权或授权过期时调用 `netdisk_auth`，只发送安全授权入口。
2. 保存当前微信文件、生成文档或文本到网盘时调用 `netdisk_save`。
3. 用户要求查看目录或最近文件时调用 `netdisk_list`。
4. 用户按关键词、文件名或类型查找网盘内容时调用 `netdisk_search`。
5. 用户明确要求分享文件时调用 `netdisk_share`。

## 安全规则

- 不索要、展示或保存百度账号密码、短信验证码、Cookie 或完整 access token。
- 授权失败时只展示用户可理解的错误，不暴露 OAuth 回调参数和堆栈。
- 分享链接属于用户数据外发；生成分享前确认目标文件。
- 不声称已保存、已分享或已删除，除非工具返回成功。
- 对同名文件要让用户确认目标，避免误分享或误保存。

## 输出

- 展示文件名、路径、大小、修改时间和分享入口等工具返回字段。
- 对链接只保留 `http` 或 `https`，移除不安全 scheme。
- 工具失败时给出重试建议或授权入口，不暴露 MCP 请求、Token 或环境变量。
