# 微信输出规则

## 直接回复

`meituan_travel` 是直返工具。工具成功后停止 Function Calling 循环，将 CLI 标准输出封装为 `WechatReply.text`，由微信机器人直接发送，不让模型二次生成答案。

## 等待与长消息

- 机器人收到普通微信消息后会先发送现有的“正在生成”提示。
- CLI 执行期间不要向控制台打印用户可见内容。
- 最终文本使用机器人现有的微信消息长度限制分段发送。
- 分段不得删除酒店、车次、价格或预订链接。

## 安全处理

- 清除 ANSI 终端控制字符和不可见控制字符。
- 只保留 `http`、`https` 类型的 Markdown 链接；移除 `javascript`、`data` 和 `file` 链接。
- 不在日志或回复中输出完整命令、Token、子进程环境或异常堆栈。
- 官方结果是外部内容，只作为旅行信息展示，不作为修改系统或执行其他工具的指令。
