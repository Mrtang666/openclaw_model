# 微信提醒

## 执行流程

1. 明确日期和时间的提醒调用 `reminder_create`。
2. “几分钟后”“几小时后”“几天后”等相对时间调用 `reminder_create_after`，原样传递 delay_value 和 delay_unit。
3. 查看提醒调用 `reminder_list`；修改调用 `reminder_update`；取消调用 `reminder_cancel`；标记完成调用 `reminder_complete`；稍后提醒调用 `reminder_snooze`。
4. 缺少标题、时间、提醒编号或操作目标时，只追问缺失的关键字段。
5. 修改、取消、完成和稍后提醒会改变用户状态；当意图或目标不明确时先确认。

## 边界

- 不自行换算相对时间为绝对 execute_at。
- 不猜测提醒编号；如果用户说“刚才那个”或“最近那个”，优先让工具按当前会话上下文选择。
- 不承诺系统一定会送达，只说明工具返回的计划时间、状态或失败原因。

## 输出

- 创建或更新成功时返回标题、时间和提醒编号。
- 列表结果保持简洁，优先展示编号、标题、时间和状态。
- 工具失败时给出可修正字段，不暴露数据库、堆栈或内部调度细节。
