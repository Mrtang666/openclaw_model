## 二十一、面试官判断标准

- **较弱回答**：只复述 README 或类名；大量使用“加缓存、加锁、上 MQ、加重试”，但说不出键、边界和失败路径。
- **合格回答**：能准确说出当前代码链路，承认实现限制，能结合具体类和数据表解释取舍。
- **优秀回答**：主动分析竞态、幂等、事务外副作用、prompt injection、SSRF、跨存储一致性，并给出渐进式改造方案。
- **高级回答**：能量化 SLO、容量与成本；用状态机、outbox、业务幂等键、评测集和可观测 trace 把方案闭环，同时避免无必要的复杂化。
