# 小红书舆情监控

## 执行流程

1. 立即采集或刷新项目关键词时调用 `xhs_monitor_collect`。
2. 查询已采集舆情内容时调用 `xhs_opinion_search`。
3. 查看风险事件列表时调用 `xhs_incident_list`。
4. 处置、流转、关闭或标记事件时调用 `xhs_incident_transition`。
5. 生成自然日或指定日期日报时调用 `xhs_daily_report`。
6. 设置告警规则调用 `xhs_alert_subscribe`；确认告警调用 `xhs_alert_acknowledge`。

## 边界规则

- 只代表已采集并完成分析的数据范围，不声称覆盖全平台。
- 不提供发布、点赞、关注、删除、私信或绕过平台限制的能力。
- 原帖访问使用工具返回的受限导航链接，并提醒可能需要登录或 App 打开。
- 删除项目或改变事件状态属于有副作用操作，必须确认目标项目或事件。
- 风险评分是解释性信号，不当作法律、品牌或公关结论。

## 输出

- 舆情结果要保留项目、关键词、时间、风险等级、证据摘要和可追踪编号。
- 日报先给总体结论，再给风险事件和建议动作。
- 工具失败时不暴露侧车 API Key、Spider 配置、Cookie、数据库字段或堆栈。
