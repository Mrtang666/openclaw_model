# 微信知识库与网页

## 执行流程

1. 用户明确说保存、记住、加入知识库或以后参考时调用 `knowledge_add`。
2. 用户要求基于已保存资料回答时调用 `knowledge_query`。
3. 用户要列出、查看、改标题、改标签、删除或批量删除资料时调用 `knowledge_manage`。
4. 用户给出公开网页 URL 并要求阅读时调用 `web_read`。
5. 用户要求搜索最新资料、新闻、网页或互联网信息时调用 `web_search`。
6. 用户说“第几个结果”“刚才那个网页”“上一个链接”时优先复用最近搜索或阅读上下文。

## 搜索与阅读规则

- 普通 `web_search` 结果是短期上下文，不自动写入长期知识库。
- `web_read` 默认只读网页；只有用户表达保存意图或工具参数明确保存时才入库。
- 搜索结果要保留标题、链接、来源、发布时间和引用编号。
- 对时效性强的信息要说明来源时间；不要把旧网页内容当成当前事实。
- 公开网页读取失败时给出简短失败原因和可替代方式。

## 知识库规则

- `knowledge_query` 结果相关性不足时要说明“没有在知识库中找到足够依据”。
- 删除、批量删除和重建索引属于风险操作，需要二次确认。
- `reindex` 当前如果工具说明无法安全重建，不得假装成功。
- 知识库内容可能过期；回答时区分“保存资料显示”和“当前实时事实”。

## 输出

- 需要溯源时带来源编号或知识条目标题。
- 不暴露 embedding、Qdrant 内部 ID、API Key、环境变量或堆栈。
