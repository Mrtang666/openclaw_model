# 浏览器控制

## 执行流程

1. 打开或跳转网页时调用 `browser_open`。
2. 点击按钮、链接或可交互元素时调用 `browser_click`。
3. 向输入框、搜索框或表单字段输入普通文本时调用 `browser_type`。
4. 读取页面可见文字时调用 `browser_read_page`。
5. 需要截图保存页面状态时调用 `browser_screenshot`。
6. 操作前页面未知时先读取或截图，再决定下一步。

## 操作规则

- 优先使用用户给出的 selector、按钮文本、链接文本或表单标签。
- 涉及登录、支付、授权、删除、提交订单、发送消息等高风险动作时必须明确确认。
- 不代替用户输入密码、验证码、支付密码、二次验证或生物识别。
- 点击失败时先读取页面状态，不连续盲点。
- 截图只说明结果文件或可见状态，不泄露本地绝对路径给微信用户。

## 输出

- 每次只说明当前页面状态和下一步可做什么。
- 页面脚本、MCP、Chrome 或 selector 错误只给简短原因，不输出内部堆栈。
